# V Rising MODs

两个独立的 V Rising BepInEx 6 IL2CPP 插件。支持并实测的游戏版本为 **1.1.13.0-r99712-b17**，Unity 2022.3.58f1，.NET 6。其他版本需重新验证。

| MOD | 插件版本 | 安装位置 | 功能 |
| --- | --- | --- | --- |
| [AutoPath](mods/autopath/README.md) | 1.2.0 | 游戏客户端 | 地图选点自动步行；蝙蝠飞行水平直线导航 |
| [MoveSpeed](mods/movespeed/README.md) | 6.0.0 | 专用服务器 | 人物、变身及骑乘使用同一移速倍率 |

安装包在 [downloads](downloads)；完整源码分别在两个 MOD 的 src 目录。

源码构建需要 .NET SDK 和 .NET 6 runtime，参考各 MOD 的说明。仓库中的 DLL 是此前实机验收的构建，SHA256 见 [校验清单](SHA256SUMS.txt)。
